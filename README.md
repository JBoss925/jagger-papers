# Jagger Papers

Standalone technical essays and architecture writeups site for [papers.jaggerbrulato.com](https://papers.jaggerbrulato.com) built on the shared [`jagger-ui`](https://github.com/JBoss925/jagger-ui) submodule.

## Development

```bash
git clone --recurse-submodules https://github.com/JBoss925/jagger-papers.git
npm install
npm run dev
```
